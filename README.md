# begao - Thiệp Mời Thôi Nôi Bé Dương An Khánh (Bé Gạo)

Trang web thiệp mời thôi nôi điện tử tương tác cho Bé Dương An Khánh.

## Chạy thử trên máy local (Run Locally)

**Yêu cầu:** Node.js

1. Cài đặt các thư viện cần thiết:
   ```bash
   npm install
   ```

2. Cấu hình biến môi trường (nếu dùng API key):
   Tạo file `.env.local` dựa trên `.env.example`.

3. Khởi chạy ứng dụng:
   ```bash
   npm run dev
   ```

4. Mở trình duyệt tại địa chỉ hiển thị trong terminal (thường là `http://localhost:5173/`).
